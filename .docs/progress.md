## 用户定过的取舍

改这些之前先问用户：

- **演示区尺寸手柄没有方向键**：按住不放时每次重复都重建动画；键盘用户用设置区的 `width` / `height` 滑块
- **按住方向键连续调滑块，每一步都重建一次动画**：不改
- **分享链接里有不合法的值时整条回默认**（不只把 basis 降级成 `auto`），并给出提示
- **basis 输入框任何失焦都恢复成生效值**，包括切去别的窗口
- **theme-color 跟系统主题**，站内切换主题时浏览器外观色不跟；不做分享图
- **演示区盒子不做右键菜单**：会挡住浏览器原生的「检查」，而对真实 DOM 右键检查正是本站用户最常做的事；「新增」与盒子位置无关、「重置」是不可撤销的全局操作，都不属于单个盒子。改为 Delete / Backspace 快捷键
- **两个页签的表格四列等宽**：用户明知代价后选定——1024 宽时每列约 82px，有诊断时明细表每行折到 121px、需要在面板内滚动
- **`noUncheckedIndexedAccess` 不开**：试过 211 个报错，没发现真缺陷；**CI 只在 push `main` 时跑**
